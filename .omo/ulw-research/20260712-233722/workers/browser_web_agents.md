### Explicit counter-search findings

- “BrowserComp” did not resolve to a distinct canonical benchmark. Search results consistently resolved to OpenAI’s **BrowseComp**, which is web-search QA rather than browser GUI control.
- The meaningful WebArena successor names are **WebArena-Verified** and **WebArena-Infinity**; original WebArena “v0.2” is merely its stable task release, not a V2 benchmark.
- No official VisualWebArena V2/Verified release was found. Related releases are **VideoWebArena**, **VAB-WebArena-Lite**, and the **ExACT-VWA** trajectory set.
- “Mind2Web successor” is overloaded: **Online-Mind2Web** is the direct live-GUI benchmark; **Mind2Web-Live/WebCanvas** adds key-node evaluation; **Multimodal-Mind2Web** adds screenshots; **Mind2Web-2** instead evaluates agentic web research.
- Yutori marketing references Navi-Bench v2, but the canonical public repo still documents v1’s 100 tasks; no independently documented public v2 task artifact was established.
- **WebStep** currently marks code and dataset “TBU”; treat the reported 1,800-task corpus as announced, not downloadable.
- **ClawsBench** releases 7,834 traces, but its repo simultaneously says task files are forthcoming.
- **WebGraphEval** reports corpus statistics but its project page does not expose an obvious primary download.
- **AutomationBench**, TravelBench, and similar tool/API workflow benchmarks were counter-searched and excluded from the main table because they do not primarily exercise browser GUI navigation.
