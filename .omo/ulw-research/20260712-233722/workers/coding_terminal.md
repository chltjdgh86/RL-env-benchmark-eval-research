## Deduplication and access findings

- The `SWE-bench/*` namespace is the current canonical namespace; many older `princeton-nlp/*` pages are aliases or legacy copies.
- `Daoguang/Multi-SWE-bench` is an older Java benchmark despite its name. The seven-language canonical dataset is `ByteDance-Seed/Multi-SWE-bench`.
- `SWE-bench_Pro-os` is the evaluation harness for the Scale dataset, not another dataset.
- The original `SWE-smith` mono-dataset is no longer actively maintained; language-specific datasets are the recommended surfaces.
- `ITBench-Scenarios` is archived; active scenarios moved into the main ITBench repository.
- The Terminal-Bench 2.0 Hugging Face repository explicitly identifies itself as a read-only mirror of the GitHub task repository.
- CyberGym’s `cybergym-iclr26` repository appears to be a release/mirror rather than a separate corpus.
- Several important sets are not fully open: DeepSWE and EnterpriseBench are gated; Terminal-Bench Pro is half public/half private; MLE-bench requires Kaggle credentials.
